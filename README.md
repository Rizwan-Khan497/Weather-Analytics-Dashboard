# 🌦️ Weather Analytics Dashboard | Excel & Power BI

## 📌 Project Overview
This project focuses on analyzing weather data using **Microsoft Excel, Power Query, Power BI, and DAX**. The goal is to clean and transform raw weather data, identify temperature patterns, evaluate data quality, and present insights through an interactive dashboard.

The dataset contains **533,312 weather records**.

## 🛠️ Tools & Technologies
- **Microsoft Excel** – Data exploration and analysis
- **Power Query** – Data cleaning and transformation
- **Power BI** – Interactive dashboard development
- **DAX** – KPI calculations and data analysis

## 📊 Dashboard Features
- Total Weather Records
- Average Temperature
- Maximum and Minimum Temperature
- Temperature Category Distribution (Cold, Moderate, Hot)
- Average Temperature by Category
- Interactive Temperature Filters
- Weather Category Summary Table
- Data Quality Analysis (Valid vs. Check Records)

## 🔍 Key Insights
- **Total Records:** 533,312
- **Average Temperature:** 12.65°C
- **Maximum Temperature:** 37°C
- **Minimum Temperature:** -16°C
- **Cold Records:** 180,181
- **Moderate Records:** 280,588
- **Hot Records:** 72,543
